Software

Essa página é dedicada aos softwares que eu uso, e porque eu uso eles. A maioria deles são softwares livres e de código aberto, e todos são gratuitos.

EndeavourOS

EndeavourOS é o nome da distribuição de Linux que eu utilizo no meu dia a dia. É uma distribuição base Arch, extremamente leve e customisável, com o ambiente de desktop padrão KDE Plasma. Eu uso ele desde outubro de 2025, foi minha primeira distribuição Linux, mas eu não me lembro como eu conheci, só me lembro que eu queria instalar uma distribuição base Arch, e brevemente considerei Manjaro ou Omarchy, mas acabei decidindo no EndeavourOS. Eu a recomendaria para qualquer um que quer todo o controle sobre o seu sistema, como no arch, mas sem ter o trabalho de instalar manualmente o sistema do zero.

Libre Office

Nem preciso falar muito sobre o Libre Office. São ferramentas de edição e visualização de documentos Open Source, similar ao Microsoft Office, mas sem bloat e sem slop.

IDE Zed

A IDE que eu uso para a maioria das tarefas de programação é o Zed, uma alternativa Open Source para o VS Code, mais estável e leve. Antes de migrar para o Linux, eu usava o VS Code, porque é o que me foi ensinado na escola. Quando passei para Linux, percebi que não era a melhor opção. após algum tempo lidando com bugs no VS Codium, resolvi usar o 'micro', um editor de texto simples no terminal. Quando voltei a estudar desenvolvimento Web, percebi que o micro não tinha as ferramentas que eu usava no VS Code. Então eu lembrei do zed, e passei a usar ele para todos os outros projetos de programação.

Firefox

Eu uso o Firefox como meu único navegador. Passei a usar ele após migrar para Linux. Apesar de ter uma empresa por trás, é Open Source, mais leve e mais seguro que Chrome. Já tentei outras alternativas como Librewolf e Icecat, a versão GNU do Firefox, mas eu não vejo motivos para migrar.
